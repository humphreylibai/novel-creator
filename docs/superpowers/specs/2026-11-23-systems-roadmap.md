# L1 · 地理系统

## 定位

> 地理是世界观的空间投影。它答四件事：**世界长什么样、归谁、大事在哪里发生、哪里不对劲。**

**不承载**：路程天数、承载力、水粮（属事件/编年史）。

## 一条最关键的决定：关系为真相，画面为投影

```
真相：只有关系
  region: 名称 / 群系 / 描述
  borders: 谁与谁接壤          part_of: 层级
  controlled_by: 谁占着（带起止年，权威在势力系统）
  marker: 奇观 / 地点 / 事件挂在哪个 region 上
  ◀ 没有坐标、没有像素、没有手绘

渲染：
  1. 按 borders 做增量布局 → 每个 region 一个大致位置
  2. Voronoi 切分 → 自动得到有形状、首尾相接的色块
  3. 群系上色 / 势力叠色 / 图钉
```

**地图不是资产。** 删掉渲染缓存，按关系重算，一模一样。改关系，地图跟着变。

## 大纲阶段完成，不是章节阶段

地理在大纲设计阶段就大体铺完（整体布局、大陆海洋、群系、奇观、势力、大事件落点）。写章节时**不改地理，只引用**；章节里出现的地理细节必须能在大纲图上找到依据。

铺满 ≠ 锁死：改任何一处，系统列出“这次改动撞到了谁”。

## 逐条长大（不是一次性生成整图）

| 大纲写到 | 画布多出 |
|---|---|
| （空） | 空画布 |
| “两块大陆，中间一道窄海” | 两块色块 + 海 |
| “北陆西岸雨林，内陆沙漠” | 分区上色；自动补山脉带（否则雨影解释不通） |
| “三个政权，甲与乙世代为敌” | 势力叠色 + 提示“甲乙必须接壤，是否新增争议区” |
| “断脉关是唯一通道” | 图钉落在两区交界 |
| “龙巢冰原嵌在草原” | 苔原色斑 + 一条反常记录 |

**增量布局**：新节点放在邻居旁边，已有位置不动。地图在你眼前“长”，不是每次换一张。

## 反常（anomaly）是一等公民

```yaml
kind: anomaly
title: 龙巢冰原
cause: E-CR-007 (吸热龙)          # 必填
center: P-SITE-022 · radius: 40km
gradient:                          # 必须有梯度，不许突变
  - { at: 0km,  temp: -15°C, biome: 苔原 }
  - { at: 15km, temp: 4°C,  biome: 针叶林 }
  - { at: 40km, temp: 26°C, biome: 雨林 }
boundary: 终年不散的雾带，雾里没有鸟叫
decay: 龙若离开超过 3 年，边界每年回退 2km
```

**三条约束**：A1 必有因果来源；A2 必有梯度与边界（**过渡带是剧情金矿**）；A3 必有代价或衰退（让它有时间性）。

## 锚定度：重构的控制阀

| 级别 | 正文写过什么 | 重构时 |
|---|---|---|
| L0 提到 | “他去过寒谷” | 自由 |
| L1 方位 | “寒谷在北” | 软约束 |
| L2 关系 | “在断脉关以东，隔一条河” | 硬约束 |
| L3 精确 | “三面环山，南面唯一出口，距海半日” | 锁死 |

**冲突三步，不许跳**：① 局部重排（只动 L0/L1）→ ② 放宽一条软约束（记 override + 理由）→ ③ 报错交人裁决。

重构前给预览：锁定不动 / 微调 / 可自由移动 / 无法满足。

空间断言从正文抽取（方位词、距离词、地形词、关系词），人确认后成为布局约束。**描写精度越高，越不能重构。**

## 校验（G 系列）

| # | 触发 | 灯 |
|---|---|---|
| G1 | 奇观无 `cause` | 🔴 |
| G2 | 群系与相邻区域/纬度矛盾且无例外标注 | ⚪ |
| G3 | 两个势力**同期**领有同一区域 | 🔴 |
| G4 | 重大事件没有落点 | 🟡 |
| G5 | 区域从未被任何事件或情节用到 | ⚪ |
| G6 | 同一势力同期领有两个互不相邻区域，且无飞地解释 | 🟡 |
| G7 | 区域无 `biome` / 成为孤岛（无 borders） | ⚪ |
| G8 | 敌对势力从不相邻（打不起来） | 🟡 |
| G9 | 反常无边界或无梯度 | 🟡 |

## 明确不做

气候自动生成器、整图程序生成、生态模拟、像素/手绘地图、局部图、行军推演。

## 待决策

- 是否做「群系自动推导」（当前：不做，群系手填 + 矛盾校验）
- 是否支持多张地图（同一世界的不同时代渲染）——当前用时间滑条解决

# L2 · 人物与组织系统

## 定位

> 人物卡最大的问题不是字段不够，是“填了也不影响写作”。形容词推不出行为。

## 三层结构

| 层 | 内容 | 变不变 |
|---|---|---|
| 底盘 | 出身、阶层、身体、语言习惯 | 基本不变 |
| 状态 | 欲望、底线、恐惧、认知、关系值 | **随时间变**，每段带 span |
| 表现 | 每个抽象词配 ≥2 个可观察表现 | 不变 |

> 不写“她多疑”，写“她从不先坐下，永远挑背靠墙的位置；她记得每个人穿的鞋”。

## 两类人物，两条入口

| | 主角型 | 功能型 |
|---|---|---|
| 起点 | 先设计，再影响剧情 | 先有剧情需求，再反推 |
| 系统做什么 | 追问：欲望与世界的公理冲突在哪 | 反推可信动机 + 提示“前面得先埋一条线” |
| 校验 | 必须被某条公理压到（`pressured_by`） | 必须有召唤它的需求 |

## 行为判定（“合理化、自动化行为”的核心）

输入 = 状态 + 情境，输出三种：

> 情境：教团出高价要她改写一段死人的记忆。
> 不会做：伪造（碰底线）｜会做：接活但只照抄｜**犹豫**：把关键一段念给雇主听，让雇主自己判断

**“绕开底线的折中”才是人物深度所在。**

## 状态段 = 弧线

```
598–605  欲望：活下去        底线：不偷
605–612  欲望：买回那段记忆   底线：不伪造
612–     欲望：毁掉记忆产业   底线：？（被破过一次）
```

硬规则：**状态变化必须由事件触发**（`changed_by: 事件`）。正文里做了违反底线的事而无解释 → 🔴，三选一：改底线 / 补事件 / 改正文。

## 暗线：三层真相

| 层 | 内容 |
|---|---|
| 真实 | 他实际是什么 |
| 剧中认知 | 其他人以为他是什么 |
| **读者认知** | 读者此刻被引导成以为他是什么 |

**读者认知 ≠ 剧中认知**，这条曲线才是作者在操控的东西。`holder` 允许是「读者」。

## 伏笔判据：双解释原则

> **一条好伏笔 = 一个行为有两解，且两解在各自层面上都成立。**

| 章 | 行为 | 表层解释 | 真实解释 |
|---|---|---|---|
| 3 | 记得三十年前每个人的名字 | 慈悲 | 他吞过他们的记忆 |
| 9 | 还脉礼不许旁观 | 尊重死者 | 不能被看见 |
| 14 | 反对记忆当铺 | 道德 | 垄断来源 |
| 21 | 救了一个记忆乞丐 | 慈善 | 那是供货人 |

只有一解的行为是**露馅**，不是伏笔。

## 认知曲线：事件自动累积

标“这件事让读者多怀疑一点”，曲线自己画出来。揭示点自动跑检查：前期佐证 < 2 条 → 硬转；佐证集中在揭示前 3 章 → 临阵磨枪。

配套：**伏笔回收表**（已埋未回收的列出来）。

## 组织（独立对象，不是人的集合）

**资源、目标、合法性来源、内部派系。**
`合法性来源`（血统/神意/钱/恐惧/功绩）是势力冲突的发动机；它一变，派系就裂。

## 校验（P 系列）

| # | 触发 | 灯 |
|---|---|---|
| P1 | 抽象特征无 ≥2 个可观察表现 | 🟡 |
| P2 | 状态变化无事件为因 | 🟡 |
| P3 | 正文行为违反底线且无事件解释 | 🔴 |
| P4 | 功能型角色无召唤需求 | 🟡 |
| P5 | 主要人物未挂在任何公理上 | 🟡 |
| P6 | 弧线首尾状态相同 | ⚪ |
| P7 | 关系单向（可能故意） | ⚪ |
| P8 | 有暗线但读者认知无过渡（0.9 直落 0） | 🟡 |
| P9 | 伏笔只有单一解释（露馅） | ⚪ |
| P10 | 表层伪装行为无伪装动机 | 🔴 |
| P11 | 伏笔已埋未回收 | 🟡 |
| P12 | 揭示无事件承载 | 🟡 |

## 待决策

- 前史是否独立成「记忆/往事」节点类型
- 关系值是否要量化（0–100）还是定性四档

# L3 · 编年史系统

## 定位

> **编年史 = 故事大纲 = 压力的时间编排。** 不是年表；`worldState(year)` 只是它的派生视图。

## 第一层产物不是事件，是压力清单

| 压力 | 来自 | 必然爆什么 |
|---|---|---|
| 三脉城单一矿脉，十二年内枯 | 公理 + 地理 | 迁徙 / 抢矿 / 矿镇解体 |
| 地脉跨境，唯一通道是断脉关 | 公理 + 地理 | 关隘争夺 |
| 她想买回记忆，底线不许伪造 | 人物（欲望×底线） | 被迫伪造的抉择 |
| 河权合法性依赖脉正，脉枯则崩 | 组织（合法性来源） | 政变 / 分裂 |
| 觉明靠吞记忆维持，供货人有限 | 暗线 | 供货链断裂 |

**压力是自动列出来的**，来源是各系统已存在的矛盾。你不想事件，你安排它们何时炸。

## 编排规则

> **一个事件至少要引爆一个压力。引爆不了任何压力的事件，就是空转。**

## 节奏：呼吸

`张力 ≈ 代价 × 不可逆性 × 波及人数`

1. 连续 3 个高张力 → 读者疲劳（中间插余波）
2. 连续 5 个低张力 → 中段空转
3. 每个高潮前必须有一段“安静”——让读者把代价算清楚

## 健康度反推上游

| 症状 | 反推 |
|---|---|
| 连续空转 | 公理没有代价 / 势力目标不冲突 |
| 平淡 | 人物未挂在公理上 / 组织没有欲望 |
| 拥挤 | 缺余波；人物没有“喘息时的生活” |
| 单线 | 人物与势力未交织 |
| 断裂 | 缺伏笔事件（回到双解释原则） |

**编年史体检不合格时，正确动作是回去改设定，不是改大纲。**

## 真相唯一 + 视角分层

每个实体对每个事件三条参数：`visible`（知不知道）、`accuracy`（理解对不对）、`version`（信的版本）。

```
误解 → 行动 → 新事件 → 新的误解      ← 这是发动机
```

## 编辑联动：提案 + 反查

每次编辑回一张三栏影响清单：🔴 必须处理 / 🟡 应当补 / ⚪ 顺带更新。

| 编辑 | 反查 |
|---|---|
| 改时间 | 因果倒置、人物年龄与存活、地理那年状态、记载年份 |
| 加事件 | 引爆哪个压力？引爆不了 → 提议向上游补一条压力 |
| 删事件 | 压力还有别人引爆吗？没有 → 🔴 大纲有洞 |
| 改参与者 | 那时活着/在场/知道吗 |
| 改真相 | 所有 holder 的 accuracy 与 version 是否要跟着改 |

**双向联动**：大纲可以反向长设定。加一条无压力事件 → 补一条压力 → 压力自动写进人物卡（记 `created_by`）。

## 派生与手改不打架

事件三态：`derived`（可覆盖）/ `accepted`（只提示）/ `written`（不动）。

## 校验（C 系列）

| # | 触发 | 灯 |
|---|---|---|
| C1 | 事件不引爆任何压力（空转） | 🔴 |
| C2 | 事件无前因且非开篇 | 🟡 |
| C3 | 连续 3 高张力（疲劳） | 🟡 |
| C4 | 连续 5 低张力（空转） | 🟡 |
| C5 | 视角 accuracy 低，却无据此的行动（白瞎一个误解） | ⚪ |
| C6 | 正文/事件结果与编年史真相矛盾 | 🔴 |

## 待决策

- 时间粒度（年 + 季节够不够；日级只在关键事件出现）
- 压力清单的自动识别准确度（是否需要人工确认环节的默认值）

# L4 · 事件系统（含场景）

## 第一等对象是故事线

编年史管“世界发生了什么”，事件系统管“发生之后，几条线怎么缠、各自带走什么、何时被撕开”。

| 主体 | 故事线 |
|---|---|
| 主角 | 想买回记忆，为此一步步往里走 |
| 甲部 | 想夺回跨境地脉，为此要拿下断脉关 |
| 河权 | 想保住合法性，必须守住脉正制度 |

**张力不在事件里，在线与线之间。**

## 打结三动作

1. **汇集**：哪些线在这里撞上、为什么非撞不可
2. **耦合**：撞完谁和谁系上了——结有七种：债 / 仇 / 盟 / 共谋知情 / 情 / 依赖 / 目标合流或分裂
3. **余波**：结在后面的幕被“拉扯”——**拉扯 = 情节**

结有**张力值**（0–100）= 一方想要的被另一方卡住的程度。拉扯结果三种：收紧 / 断裂 / 解开。

## 结的生命周期

```
第一幕末  系上（他从火里拖出她）        张力 40
第二幕中  甲部使者提债                  张力 65
第二幕末  要她伪造记忆抵债（撞底线）      张力 85
第三幕    她绕道，债没还成，反欠新结      70 → 转新结
结尾      向导已死，这笔债永远还不上了    解开（无解之解）
```

**一条结，四次拉扯，横跨三幕。**

## 四类影响对象

| 对象 | 影响 |
|---|---|
| 人物 | 状态、关系、认知、能力 |
| 世界 | 公理被验证/挑战、制度变、地理变 |
| 组织 | 合法性、资源、派系 |
| **剧情** | **结构本身**：开线、收线、升悬念、换舞台、换视角 |

第四类最易忘，但它决定事件是否“白发生”。

## 四尺度 + 尺度决定校验强度

| 尺度 | 承载 | 数量级 | 必须引爆压力 | 伏笔 | 必须改变 |
|---|---|---|---|---|---|
| 历史 | 故事之前的大事 | 少量 | ❌ | 作为伏笔源 | 作为背景 |
| 世界 | 全局重大变化 | 3–7 | ✅ ≥1 | ✅ ≥3 处跨尺度 | 世界状态 |
| 地区 | 一地区的人物与走向 | 每区 3–8 | ✅ ≥1 | 建议 ≥1 | 地区状态 |
| 个人 | 少数角色 | 大量 | ❌ 不必 | ❌ 不必 | **人物状态 / 关系 / 展示其表现** |

> 个人事件底线只有一条：**要么改变人物，要么让人看见人物。**

## 尺度是投影，不是分类

```
世界事件：断脉关之战
  ├─ 地区投影：北境三区易主、商路改道
  ├─ 地区投影：河权主战派失势
  └─ 个人投影：她被向导救出（结①）、觉明收了三个法师（结④）
```

**没有低尺度投影的世界事件，读者不会疼。**

## 草蛇灰线 = 跨尺度伏笔

> 世界事件的伏笔必须埋在**不同尺度、不同主体、不同章节**。

四条伏笔：世界尺度（公理陈述）· 地区尺度（地方志）· 个人尺度 ×2（记得所有人 / 救记忆乞丐），跨度二十章。

## 尺度节奏视图

```
世界 ┤        ●              ●         ●
地区 ┤   ●         ●    ●         ●
个人 ┤ ●●●●●●●●●●●●●●●●●●●●●●●●●●●●
     └────┬────┬────┬────┬────┬────┬──
          1    10   20   30   40   50 章
```

一眼查出：中段塌陷 / 高潮拥挤 / 尺度断层。

## 场景（归属本系统）

四格：**目标 / 障碍 / 转折 / 结果**。填不满不该写。

## 总账视图（弹药库）

```
未解的结（12）
  ①债  主角→甲部   张力 65  预计拉扯：第二幕中  ⚠ 已过 8 章未动
  ④知情 主角→觉明  张力 80  预计拉扯：第三幕（暗线收束）
已解（7）  断裂（2）  有意不解（1）
```

## 校验（E 系列）

| # | 触发 | 灯 |
|---|---|---|
| E1 | 事件只有一条线经过（是过场，不是事件） | 🟡 |
| E2 | 多线相撞却没产生任何结（白撞） | 🔴 |
| E3 | 结从未被拉扯（线头） | 🟡 |
| E4 | 拉扯时与登记不一致 | 🔴 |
| E5 | 受重大影响的主体无任何反应（工具人） | 🟡 |
| E6 | 同一结被反复拉扯太多（张力耗尽） | ⚪ |
| E7 | 事件未对剧情结构产生任何影响（结构空转） | 🟡 |
| E8 | 张力已高却迟迟不拉 | ⚪ |
| E9 | 世界事件只改变了一个人的状态（名不副实） | 🔴 |
| E10 | 世界事件伏笔全在同一尺度/同章（不够草蛇灰线） | 🟡 |
| E11 | 世界事件无低尺度投影（只是战报） | 🟡 |
| E12 | 个人事件既未改变人物也未展示人物 | 🟡 |
| E13 | 中段连续 N 章无地区级以上事件 | ⚪ |
| E14 | 个人事件影响外溢全局但未登记（可能是宝藏） | ⚪ |

# L5 · 对话系统（排演系统）

## 定位

**这是实际写作层，也是整套系统的出口。** 它不是校验器，是能演一场戏的 agent 剧场。

## 架构

```
              章节简报（编年史 + 事件系统）
              本章必须达成的转折 / 必须引爆的压力 / 场景四格
                            ↓
                    ┌───────────────┐
                    │  导演 agent    │  定舞台、排节拍、必要时介入
                    └───────┬───────┘
                            ↓ 开演
        ┌──────────┬────────┴────────┬──────────┐
     主角 agent  觉明 agent      甲部使者 agent  ……
        └──────────┴────────┬────────┴──────────┘
                            ↓
                      场记（剧本式记录）
                            ↓
              事实抽取 → 采纳后回流到六个系统
```

## 角色 agent 的输入包

```yaml
我是谁      抄名匠出身，二十四岁；说话短，常常不说完
我要什么    从觉明口中问出「还脉礼」那晚死的是谁
我不能      不能承认我翻过他的柜子
我怕什么    他会发现我在抄他的名字
我知道      觉明是教团最年长的善人（置信 0.75）
我不知道    他靠吞取记忆维持           ← 隔离
我信错了    还脉礼是慈悲之举（置信 0.90）
我欠着谁    甲部一条命（未还）
此刻处境    屋里只有我们两个，他刚替我倒了茶
我的说法    短句；从不叫「大人」；紧张时重复对方的词
```

## 最大的架构红利：角色隔离 = 信息差矩阵

不需要手工维护“A 知道什么、B 知道什么”。每个 agent 只拿到自己的信念包，**信息差物理成立**，而且结构上不可能说出自己不知道的事。

D3（说出不可能知道的事）从此不靠检查。

## 导演 agent 的约束

只管三件事：摆舞台 / 排节拍（几个回合、哪句翻面、必须达成的转折）/ 喊停。

**不得替角色做决定，也不得让角色说出他不知道的事。** 否则就是提线木偶戏。

## 场记 → 事实抽取 → 采纳后回流

| 抽取事实 | 回流到 |
|---|---|
| 主角对觉明 accuracy 0.75 → 0.60 | 人物认知 / 编年史视角 |
| 新结：她撒了第一个谎 | 事件系统 |
| 读者认知曲线 −0.05 | 编年史 |
| 觉明对她的怀疑 +1 | 关系值 |

**演出永远是草稿，回流必须由作者点采纳**——否则世界会被模型幻觉悄悄改写。

## 作者的位置

**定本章目标与障碍 → agent 开演 → 挑哪几句留下 / 改哪句 → 采纳的进正文。**

## 四个已知风险

| 风险 | 症状 | 对策 |
|---|---|---|
| 人物卡朗读机 | 开口就背设定 | 一句话塞 2 个以上设定点 → 重演 |
| 跑偏 | 角色互相带跑 | 导演每 N 轮检查转折是否达成 |
| 干瘪 | 人物卡空 → 全是空话 | 开演前检查输入包完整度，缺“我不能/我怕”拒绝开演 |
| 成本 | 每章多 agent 演出 token 高 | 只对关键场景演出；过渡场景用简版 |

## 校验（D 系列）

| # | 触发 | 灯 |
|---|---|---|
| D1 | 台词没有目标（寒暄） | 🟡 |
| D2 | 说出对方已经知道的事（说明文） | 🟡 |
| D3 | 说出自己不可能知道的事（越 `visible`） | 🔴 |
| D4 | 语域漂移且未标记伪装/失控 | 🟡 |
| D5 | 全场无人改变立场或认知 | 🟡 |
| D6 | 潜台词为零 | ⚪ |
| D7 | 称谓不合阶层/关系/场合 | 🟡 |
| D8 | 一段台词塞 3 个以上设定信息（信息倾倒） | 🟡 |

**D2 与 D8 是“像说明文”的两种成因，且都能纯数据判定。**

## 分期

- **P2**：输入包结构、场记存储、事实抽取（先能存能抽，不演）
- **P3**：单场景排演（一导演 + 两角色）
- **P4**：多角色、跨场景、重演与局部重演

## 待决策

- 演出引擎的模型路由（是否用更强的模型演主角）
- 场记与正文的关系（场记是正文的草稿，还是平行产物）
