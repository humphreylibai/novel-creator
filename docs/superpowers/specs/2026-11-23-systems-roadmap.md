# L1 · 地理系统

## 定位

> 地理是世界观的空间投影。它答四件事：**世界长什么样、归谁、大事在哪里发生、哪里不对劲。**

**不承载**：路程天数、承载力、水粮（属事件/编年史）。

## 一条最关键的决定：关系为真相，画面为投影

```
真相：只有关系
  region: 名称 / 群系 / 描述
  borders: 谁与谁接壤          part_of: 层级
  controlled_by: 谁占着（带起止年，权威在势力系统）
  marker: 奇观 / 地点 / 事件挂在哪个 region 上
  ◀ 没有坐标、没有像素、没有手绘

渲染：
  1. 按 borders 做增量布局 → 每个 region 一个大致位置
  2. Voronoi 切分 → 自动得到有形状、首尾相接的色块
  3. 群系上色 / 势力叠色 / 图钉
```

**地图不是资产。** 删掉渲染缓存，按关系重算，一模一样。改关系，地图跟着变。

## 大纲阶段完成，不是章节阶段

地理在大纲设计阶段就大体铺完（整体布局、大陆海洋、群系、奇观、势力、大事件落点）。写章节时**不改地理，只引用**；章节里出现的地理细节必须能在大纲图上找到依据。

铺满 ≠ 锁死：改任何一处，系统列出“这次改动撞到了谁”。

## 逐条长大（不是一次性生成整图）

| 大纲写到 | 画布多出 |
|---|---|
| （空） | 空画布 |
| “两块大陆，中间一道窄海” | 两块色块 + 海 |
| “北陆西岸雨林，内陆沙漠” | 分区上色；自动补山脉带（否则雨影解释不通） |
| “三个政权，甲与乙世代为敌” | 势力叠色 + 提示“甲乙必须接壤，是否新增争议区” |
| “断脉关是唯一通道” | 图钉落在两区交界 |
| “龙巢冰原嵌在草原” | 苔原色斑 + 一条反常记录 |

**增量布局**：新节点放在邻居旁边，已有位置不动。地图在你眼前“长”，不是每次换一张。

## 反常（anomaly）是一等公民

```yaml
kind: anomaly
title: 龙巢冰原
cause: E-CR-007 (吸热龙)          # 必填
center: P-SITE-022 · radius: 40km
gradient:                          # 必须有梯度，不许突变
  - { at: 0km,  temp: -15°C, biome: 苔原 }
  - { at: 15km, temp: 4°C,  biome: 针叶林 }
  - { at: 40km, temp: 26°C, biome: 雨林 }
boundary: 终年不散的雾带，雾里没有鸟叫
decay: 龙若离开超过 3 年，边界每年回退 2km
```

**三条约束**：A1 必有因果来源；A2 必有梯度与边界（**过渡带是剧情金矿**）；A3 必有代价或衰退（让它有时间性）。

## 锚定度：重构的控制阀

| 级别 | 正文写过什么 | 重构时 |
|---|---|---|
| L0 提到 | “他去过寒谷” | 自由 |
| L1 方位 | “寒谷在北” | 软约束 |
| L2 关系 | “在断脉关以东，隔一条河” | 硬约束 |
| L3 精确 | “三面环山，南面唯一出口，距海半日” | 锁死 |

**冲突三步，不许跳**：① 局部重排（只动 L0/L1）→ ② 放宽一条软约束（记 override + 理由）→ ③ 报错交人裁决。

重构前给预览：锁定不动 / 微调 / 可自由移动 / 无法满足。

空间断言从正文抽取（方位词、距离词、地形词、关系词），人确认后成为布局约束。**描写精度越高，越不能重构。**

## 校验（G 系列）

| # | 触发 | 灯 |
|---|---|---|
| G1 | 奇观无 `cause` | 🔴 |
| G2 | 群系与相邻区域/纬度矛盾且无例外标注 | ⚪ |
| G3 | 两个势力**同期**领有同一区域 | 🔴 |
| G4 | 重大事件没有落点 | 🟡 |
| G5 | 区域从未被任何事件或情节用到 | ⚪ |
| G6 | 同一势力同期领有两个互不相邻区域，且无飞地解释 | 🟡 |
| G7 | 区域无 `biome` / 成为孤岛（无 borders） | ⚪ |
| G8 | 敌对势力从不相邻（打不起来） | 🟡 |
| G9 | 反常无边界或无梯度 | 🟡 |

## 明确不做

气候自动生成器、整图程序生成、生态模拟、像素/手绘地图、局部图、行军推演。

## 待决策

- 是否做「群系自动推导」（当前：不做，群系手填 + 矛盾校验）
- 是否支持多张地图（同一世界的不同时代渲染）——当前用时间滑条解决

# L2 · 人物与势力系统

## 定位

> 人物卡最大的问题不是字段不够，是“填了也不影响写作”。形容词推不出行为。

## 三层结构

| 层 | 内容 | 变不变 |
|---|---|---|
| 底盘 | 出身、阶层、身体、语言习惯 | 基本不变 |
| 状态 | 欲望、底线、恐惧、认知、关系值 | **随时间变**，每段带 span |
| 表现 | 每个抽象词配 ≥2 个可观察表现 | 不变 |

> 不写“她多疑”，写“她从不先坐下，永远挑背靠墙的位置；她记得每个人穿的鞋”。

## 两类人物，两条入口

| | 主角型 | 功能型 |
|---|---|---|
| 起点 | 先设计，再影响剧情 | 先有剧情需求，再反推 |
| 系统做什么 | 追问：欲望与世界的公理冲突在哪 | 反推可信动机 + 提示“前面得先埋一条线” |
| 校验 | 必须被某条公理压到（`pressured_by`） | 必须有召唤它的需求 |

## 行为判定（“合理化、自动化行为”的核心）

输入 = 状态 + 情境，输出三种：

> 情境：教团出高价要她改写一段死人的记忆。
> 不会做：伪造（碰底线）｜会做：接活但只照抄｜**犹豫**：把关键一段念给雇主听，让雇主自己判断

**“绕开底线的折中”才是人物深度所在。**

## 状态段 = 弧线

```
598–605  欲望：活下去        底线：不偷
605–612  欲望：买回那段记忆   底线：不伪造
612–     欲望：毁掉记忆产业   底线：？（被破过一次）
```

硬规则：**状态变化必须由事件触发**（`changed_by: 事件`）。正文里做了违反底线的事而无解释 → 🔴，三选一：改底线 / 补事件 / 改正文。

## 暗线：三层真相

| 层 | 内容 |
|---|---|
| 真实 | 他实际是什么 |
| 剧中认知 | 其他人以为他是什么 |
| **读者认知** | 读者此刻被引导成以为他是什么 |

**读者认知 ≠ 剧中认知**，这条曲线才是作者在操控的东西。`holder` 允许是「读者」。

## 伏笔判据：双解释原则

> **一条好伏笔 = 一个行为有两解，且两解在各自层面上都成立。**

| 章 | 行为 | 表层解释 | 真实解释 |
|---|---|---|---|
| 3 | 记得三十年前每个人的名字 | 慈悲 | 他吞过他们的记忆 |
| 9 | 还脉礼不许旁观 | 尊重死者 | 不能被看见 |
| 14 | 反对记忆当铺 | 道德 | 垄断来源 |
| 21 | 救了一个记忆乞丐 | 慈善 | 那是供货人 |

只有一解的行为是**露馅**，不是伏笔。

## 认知曲线：事件自动累积

标“这件事让读者多怀疑一点”，曲线自己画出来。揭示点自动跑检查：前期佐证 < 2 条 → 硬转；佐证集中在揭示前 3 章 → 临阵磨枪。

配套：**伏笔回收表**（已埋未回收的列出来）。

## 势力（组织）：独立对象，不是人的集合

> **组织的核心不是“一群人的集合”，是“一个会偏离成员意图的行动者”。**

所有好看的组织戏都长在这条缝里：**上头的意思 ≠ 底下做的事**。若组织只是“把人物打上标签归到一起”，它就是个文件夹，不会产生任何情节。

（模型层统一叫 `组织`，界面叫**势力**——因为要管的不只是组织，还有王朝、部落、行会。）

### 六件东西

```yaml
组织：教团
subtype: 教会
目标        垄断记忆来源，维持“还脉”的话语权
合法性来源   神意 —— 还脉是替死者还债，所以教团有权处置死者
资源        无字塔、供养体系、内典、抄名匠行会
派系        清洗者（觉明）· 行会 · 反对派
状态段      纪元 350–611 稳固 · 612– 分裂
领地        北陆中部 三座塔城（与地理 controlled_by 联动）
```

**合法性来源是最有用的一个字段**：它同时定义谁必须服从、怎么才算正当、以及**什么情况下会崩**。

| 合法性来源 | 凭什么听你的 | 崩解条件 |
|---|---|---|
| 血统 | 你是先王之后 | 血统被证伪 / 绝嗣 |
| 神意 | 神选了你 | 神迹失效 / 灾难被解释为天罚 |
| 钱 | 你发饷 | 财源断 |
| 恐惧 | 你杀得动 | 有人杀回来 |
| 功绩 | 你打赢过 | 打输了 |
| 程序 | 规矩如此 | 规矩被绕过一次且无人受罚 |

**“合法性来源失效 → 组织必然裂解”是可校验的**，比“势力强弱”这种模糊判断硬得多。

### 核心机制：命令失真

```
领袖意图：借断脉关之战削弱法师团
   ↓ 三层传递，每层按自己的利益过滤
将军理解：拿下关，顺便让法师团死人
   ↓
执行者做的：关破时“来不及”救那几个法师
   ↓
结果：法师团记下这笔仇 —— 一个结（盟 → 仇）
```

这不是阴谋，是**结构性的**：

```yaml
指挥链：
  - { 层: 决策层, 失真度: 0,   过滤方式: — }
  - { 层: 执行层, 失真度: 0.4, 过滤方式: 保命优先 }
  - { 层: 基层,   失真度: 0.7, 过滤方式: 只认直接上级 }
```

用处：**每当你写“组织做的事”，系统会问“这是谁的意图”**。答不上来，说明这一步是作者在推、不是组织在动——读者会觉得“这个组织怎么突然变蠢了”。

### 政权：组织的 subtype，多三样东西

| | 一般组织 | 政权（国家/王朝/城邦） |
|---|---|---|
| 领土 | 有驻地，不排他 | **排他**：边界内不许第二个主权 |
| 人 | **成员**，可退出（退出=叛逃） | **臣民**，无退出权（离开=流亡，需别国接收） |
| 正当性 | 通常单一来源 | **复合**：血统 + 神意 + 程序，缺一就裂 |
| 资源 | 交易 / 捐赠 / 掠夺 | **抽取**（税、役、征发） |
| 承认 | 不需要 | **需要**：被不被别的政权承认 |

政权只加三个可选字段：`领土`（实控 / **宣称** 分开记）、`臣民`、`承认状态`。不新建对象。

subtype 与默认合法性来源：

| subtype | 默认合法性 | 崩解触发 |
|---|---|---|
| 政权 | 程序 + 神意 | 程序被绕过而无人受罚 |
| 教团 | 神意 | 神迹失效 / 灾难被解释为天罚 |
| 门派 | 功绩 + 传承 | 比试输了 / 传承断绝 |
| 商会 / 行会 | 钱 | 财源断 |
| 军队 | 恐惧 + 钱 | 欠饷 |
| 家族 / 氏族 | 血统 | 绝嗣 / 血统被证伪 |
| 秘密结社 | 共同秘密 | 秘密泄露 |
| 部落 / 联盟 | 血统 + 生存 | 生存压力转移 |

新建时自动带出默认值，你只改不填——这是“题材扩展包”的正确用法：**默认值是起手式，不是约束**。

### 隶属不是树，是网

教团跨两个政权；甲部某支军队同时效忠甲部与旧王室；行会寄生在教团的供养体系里。所以 `隶属` 是多重归属。

### 派系：组织内的组织

派系有同样的六件东西，只是规模小。**派系与组织目标的偏差 = 分裂的倒计时**：

```
教团总目标   垄断记忆来源
清洗者       维持“还脉”神圣性（一致，手段更极端）
行会         卖记忆赚更多钱（偏差 60% —— 在蛀空合法性）
反对派       公开还脉真相（偏差 100% —— 要推翻）
```

偏差过阈 → 应有一次分裂事件 → 校验会问：“行会已经蛀了二十年，为什么还没翻脸？”

### 关系图：势力页的主视图

**一条关系有「表面」与「真相」两层**（与人物暗线同一套）：

```
表面：甲部 ──同盟──▶ 教团      真相：甲部 ──利用──▶ 教团
表面：觉明 ──效忠──▶ 教团      真相：觉明 ──秘密从属──▶ 甲部
```

界面开关：**[表面] / [真相] / [叠加]**（真相用红色虚线叠在灰实线上）。**没有这个开关，关系图只能画“大家知道的”，永远只是背景板。**

边有十种：

| 类型 | 方向 | 例 | 特有属性 |
|---|---|---|---|
| 效忠 | 人 → 组织 | 将军效忠王朝 | 忠诚度、可否退出 |
| 隶属 | 组织 → 组织 | 行会隶属教团 | 是否多重、可否分离 |
| 血缘/婚姻 | 人 ↔ 人 | 她是旧王的私生女 | 公开 / 隐秘 |
| 庇护 | 强 → 弱 | 脉正庇护抄名匠 | 交换条件 |
| 债务 | 负债 → 债权 | 主角欠甲部一条命 | 被讨过没有 |
| 同盟 | 对称 | 甲部 × 教团 | 条件、期限 |
| 敌对 | 对称 | 河权 × 甲部 | 仇因、是否宣战 |
| 竞争 | 对称 | 两商会抢同一条商路 | 争夺对象 |
| 承认 | 政权 ↔ 政权 | 甲部不承认河权 | 单向 / 双向 |
| **把柄/知情** | 知情方 → 当事人 | 主角看见觉明在尸堆旁做的事 | 是否已揭露 |

每条边带三样：**强度（0–100）、起止年、可见性（谁知道这段关系存在）**。第三样直接喂给对话系统的潜台词。

**三种视图**：

| 视图 | 看什么 | 什么时候用 |
|---|---|---|
| **图** | 形状：谁在中心、谁被孤立、谁在夹缝 | 判断结构 |
| **矩阵** | 势力 × 势力全览格（盟/敌/债/认） | 一眼扫完政治格局；空格就是“没关系” |
| **清单** | 选中实体的关系逐条读（强度、起止、谁知道） | 查细节、改数据 |

**默认不画全图**：以选中实体为中心，只画一跳邻居（最多两跳）。

**布局按“谁和谁有关系”自动分簇，不按阵营摆。** 分簇后会出现意外：本该在两边的两个组织被摆到一起——那通常说明你写出了自己没意识到的同盟。

### 校验（O 系列）

| # | 触发 | 灯 |
|---|---|---|
| O1 | 组织没有合法性来源 | 🟡 它凭什么存在 |
| O2 | **合法性来源所依赖的节点失效，组织状态却没变** | 🔴 脉枯了，教团凭什么还在 |
| O3 | 组织有目标，但没有任何角色能执行它 | 🟡 组织成了抽象名词 |
| O4 | 派系目标与组织目标完全一致 | ⚪ 扁平，没有内部张力 |
| O5 | 组织没有领地也没有资源来源 | 🟡 凭空存在 |
| O6 | 组织是事件参与方，但没指定任何成员 | 🟡 是名词，不是行动者 |
| O7 | 组织状态变更无事件驱动 | 🟡 同人物弧线 |
| O8 | 命令链设了失真，却从未产生偏差后果 | ⚪ 白设了 |
| O9 | subtype=政权，但没有指挥链 | 🟡 它只是旗号，不是国家 |
| O10 | 组织同时隶属两个敌对政权（双重效忠） | 🟡 夹缝还是写漏了 |
| O11 | 宣称领土与实控领土不一致且未标注 | ⚪ 「宣称」≠「实控」 |
| O12 | 实体在关系图上没有任何边（孤岛） | 🟡 它在故事里没有位置 |
| O13 | 存在隐藏关系，但从未被任何章节揭示 | 🟡 埋了没人挖 |
| O14 | 敌对双方从未在任何事件里相遇 | 🟡 结了仇却没打过 |

**O2 与 O13 最值钱**：前者把“设定之间的因果”变成可检测；后者是“伏笔回收率”在关系层的版本——红色虚线埋了几条、用了几条，一目了然。

## 校验（P 系列 · 人物）

| # | 触发 | 灯 |
|---|---|---|
| P1 | 抽象特征无 ≥2 个可观察表现 | 🟡 |
| P2 | 状态变化无事件为因 | 🟡 |
| P3 | 正文行为违反底线且无事件解释 | 🔴 |
| P4 | 功能型角色无召唤需求 | 🟡 |
| P5 | 主要人物未挂在任何公理上 | 🟡 |
| P6 | 弧线首尾状态相同 | ⚪ |
| P7 | 关系单向（可能故意） | ⚪ |
| P8 | 有暗线但读者认知无过渡（0.9 直落 0） | 🟡 |
| P9 | 伏笔只有单一解释（露馅） | ⚪ |
| P10 | 表层伪装行为无伪装动机 | 🔴 |
| P11 | 伏笔已埋未回收 | 🟡 |
| P12 | 揭示无事件承载 | 🟡 |

## 待决策

- 前史是否独立成「记忆/往事」节点类型
- 关系值是否要量化（0–100）还是定性四档

# L3 · 编年史系统

## 定位

> **编年史 = 故事大纲 = 压力的时间编排。** 不是年表；`worldState(year)` 只是它的派生视图。

## 第一层产物不是事件，是压力清单

| 压力 | 来自 | 必然爆什么 |
|---|---|---|
| 三脉城单一矿脉，十二年内枯 | 公理 + 地理 | 迁徙 / 抢矿 / 矿镇解体 |
| 地脉跨境，唯一通道是断脉关 | 公理 + 地理 | 关隘争夺 |
| 她想买回记忆，底线不许伪造 | 人物（欲望×底线） | 被迫伪造的抉择 |
| 河权合法性依赖脉正，脉枯则崩 | 组织（合法性来源） | 政变 / 分裂 |
| 觉明靠吞记忆维持，供货人有限 | 暗线 | 供货链断裂 |

**压力是自动列出来的**，来源是各系统已存在的矛盾。你不想事件，你安排它们何时炸。

## 编排规则

> **一个事件至少要引爆一个压力。引爆不了任何压力的事件，就是空转。**

## 节奏：呼吸

`张力 ≈ 代价 × 不可逆性 × 波及人数`

1. 连续 3 个高张力 → 读者疲劳（中间插余波）
2. 连续 5 个低张力 → 中段空转
3. 每个高潮前必须有一段“安静”——让读者把代价算清楚

## 健康度反推上游

| 症状 | 反推 |
|---|---|
| 连续空转 | 公理没有代价 / 势力目标不冲突 |
| 平淡 | 人物未挂在公理上 / 组织没有欲望 |
| 拥挤 | 缺余波；人物没有“喘息时的生活” |
| 单线 | 人物与势力未交织 |
| 断裂 | 缺伏笔事件（回到双解释原则） |

**编年史体检不合格时，正确动作是回去改设定，不是改大纲。**

## 真相唯一 + 视角分层

每个实体对每个事件三条参数：`visible`（知不知道）、`accuracy`（理解对不对）、`version`（信的版本）。

```
误解 → 行动 → 新事件 → 新的误解      ← 这是发动机
```

## 编辑联动：提案 + 反查

每次编辑回一张三栏影响清单：🔴 必须处理 / 🟡 应当补 / ⚪ 顺带更新。

| 编辑 | 反查 |
|---|---|
| 改时间 | 因果倒置、人物年龄与存活、地理那年状态、记载年份 |
| 加事件 | 引爆哪个压力？引爆不了 → 提议向上游补一条压力 |
| 删事件 | 压力还有别人引爆吗？没有 → 🔴 大纲有洞 |
| 改参与者 | 那时活着/在场/知道吗 |
| 改真相 | 所有 holder 的 accuracy 与 version 是否要跟着改 |

**双向联动**：大纲可以反向长设定。加一条无压力事件 → 补一条压力 → 压力自动写进人物卡（记 `created_by`）。

## 派生与手改不打架

事件三态：`derived`（可覆盖）/ `accepted`（只提示）/ `written`（不动）。

## 校验（C 系列）

| # | 触发 | 灯 |
|---|---|---|
| C1 | 事件不引爆任何压力（空转） | 🔴 |
| C2 | 事件无前因且非开篇 | 🟡 |
| C3 | 连续 3 高张力（疲劳） | 🟡 |
| C4 | 连续 5 低张力（空转） | 🟡 |
| C5 | 视角 accuracy 低，却无据此的行动（白瞎一个误解） | ⚪ |
| C6 | 正文/事件结果与编年史真相矛盾 | 🔴 |

## 待决策

- 时间粒度（年 + 季节够不够；日级只在关键事件出现）
- 压力清单的自动识别准确度（是否需要人工确认环节的默认值）

# L4 · 事件系统

## 第一等对象是故事线

编年史管“世界发生了什么”，事件系统管“发生之后，几条线怎么缠、各自带走什么、何时被撕开”。

| 主体 | 故事线 |
|---|---|
| 主角 | 想买回记忆，为此一步步往里走 |
| 甲部 | 想夺回跨境地脉，为此要拿下断脉关 |
| 河权 | 想保住合法性，必须守住脉正制度 |

**张力不在事件里，在线与线之间。**

## 打结三动作

1. **汇集**：哪些线在这里撞上、为什么非撞不可
2. **耦合**：撞完谁和谁系上了——结有七种：债 / 仇 / 盟 / 共谋知情 / 情 / 依赖 / 目标合流或分裂
3. **余波**：结在后面的幕被“拉扯”——**拉扯 = 情节**

结有**张力值**（0–100）= 一方想要的被另一方卡住的程度。拉扯结果三种：收紧 / 断裂 / 解开。

## 结的生命周期

```
第一幕末  系上（他从火里拖出她）        张力 40
第二幕中  甲部使者提债                  张力 65
第二幕末  要她伪造记忆抵债（撞底线）      张力 85
第三幕    她绕道，债没还成，反欠新结      70 → 转新结
结尾      向导已死，这笔债永远还不上了    解开（无解之解）
```

**一条结，四次拉扯，横跨三幕。**

## 四类影响对象

| 对象 | 影响 |
|---|---|
| 人物 | 状态、关系、认知、能力 |
| 世界 | 公理被验证/挑战、制度变、地理变 |
| 组织 | 合法性、资源、派系 |
| **剧情** | **结构本身**：开线、收线、升悬念、换舞台、换视角 |

第四类最易忘，但它决定事件是否“白发生”。

## 四尺度 + 尺度决定校验强度

| 尺度 | 承载 | 数量级 | 必须引爆压力 | 伏笔 | 必须改变 |
|---|---|---|---|---|---|
| 历史 | 故事之前的大事 | 少量 | ❌ | 作为伏笔源 | 作为背景 |
| 世界 | 全局重大变化 | 3–7 | ✅ ≥1 | ✅ ≥3 处跨尺度 | 世界状态 |
| 地区 | 一地区的人物与走向 | 每区 3–8 | ✅ ≥1 | 建议 ≥1 | 地区状态 |
| 个人 | 少数角色 | 大量 | ❌ 不必 | ❌ 不必 | **人物状态 / 关系 / 展示其表现** |

> 个人事件底线只有一条：**要么改变人物，要么让人看见人物。**

## 尺度是投影，不是分类

```
世界事件：断脉关之战
  ├─ 地区投影：北境三区易主、商路改道
  ├─ 地区投影：河权主战派失势
  └─ 个人投影：她被向导救出（结①）、觉明收了三个法师（结④）
```

**没有低尺度投影的世界事件，读者不会疼。**

## 草蛇灰线 = 跨尺度伏笔

> 世界事件的伏笔必须埋在**不同尺度、不同主体、不同章节**。

四条伏笔：世界尺度（公理陈述）· 地区尺度（地方志）· 个人尺度 ×2（记得所有人 / 救记忆乞丐），跨度二十章。

## 尺度节奏视图

```
世界 ┤        ●              ●         ●
地区 ┤   ●         ●    ●         ●
个人 ┤ ●●●●●●●●●●●●●●●●●●●●●●●●●●●●
     └────┬────┬────┬────┬────┬────┬──
          1    10   20   30   40   50 章
```

一眼查出：中段塌陷 / 高潮拥挤 / 尺度断层。

## 场景（schema 属本系统，使用在 L6）

四格：**目标 / 障碍 / 转折 / 结果**。填不满不该写。
本系统只定义 schema；场景的编排与排演属 L6。

## 总账视图（弹药库）

```
未解的结（12）
  ①债  主角→甲部   张力 65  预计拉扯：第二幕中  ⚠ 已过 8 章未动
  ④知情 主角→觉明  张力 80  预计拉扯：第三幕（暗线收束）
已解（7）  断裂（2）  有意不解（1）
```

## 校验（E 系列）

| # | 触发 | 灯 |
|---|---|---|
| E1 | 事件只有一条线经过（是过场，不是事件） | 🟡 |
| E2 | 多线相撞却没产生任何结（白撞） | 🔴 |
| E3 | 结从未被拉扯（线头） | 🟡 |
| E4 | 拉扯时与登记不一致 | 🔴 |
| E5 | 受重大影响的主体无任何反应（工具人） | 🟡 |
| E6 | 同一结被反复拉扯太多（张力耗尽） | ⚪ |
| E7 | 事件未对剧情结构产生任何影响（结构空转） | 🟡 |
| E8 | 张力已高却迟迟不拉 | ⚪ |
| E9 | 世界事件只改变了一个人的状态（名不副实） | 🔴 |
| E10 | 世界事件伏笔全在同一尺度/同章（不够草蛇灰线） | 🟡 |
| E11 | 世界事件无低尺度投影（只是战报） | 🟡 |
| E12 | 个人事件既未改变人物也未展示人物 | 🟡 |
| E13 | 中段连续 N 章无地区级以上事件 | ⚪ |
| E14 | 个人事件影响外溢全局但未登记（可能是宝藏） | ⚪ |

## 待决策

- 结的“张力值”是否要精确数值，还是定性四档
- 是否提供“重排建议”（把未拉的结排进后面几章）

# L5 · 篇章结构系统（卷 / 集 / 章）

## 定位

**它把“什么发生”排成“第几卷、哪一集、哪一章”。** 它不生产事件——**它切编年史**。

> 编年史只有一个，是那条时间轴本身。设定阶段写它（产物），规划阶段切它（原料）。

## 三级钻取：三种单位，三种切法

| 单位 | 怎么切 | 本质 | 数据结构 |
|---|---|---|---|
| **卷** | 在编年史上**框选一段范围** | 一段时间 | `{ from, to, contains: eventIds[] }` |
| **集** | 在卷内**选中若干事件** | 一组并行的事 | `{ volumeId, lines: [{ subject, eventIds }] }` |
| **章** | 把**一件具体的小事**挂进来 | 一个落点 | `{ episodeId, lineId, concrete: {动作, 台词, 细节} }` |

**卷是时间窗，集是事件包，章是落点。** 集不按时间切，因为多条线可以跨不同时间点并行推进。

## 规划阶段不能改编年史

**能改**：怎么分组、怎么排序、每个事件挂到哪一章、卷叫什么、集里做几条线。
**不能改**：事件的时间、参与方、真相。

编年史是唯一真相。规划时发现“顺序不对”，正确动作是**回设定阶段改编年史**。界面上：时间字段是灰的，旁边一句「回设定阶段修改」。

## 约束的定位：不硬拦，只提醒

框选与装箱时实时给灯，但**永不阻止操作**：

| 何时 | 检查 | 灯 |
|---|---|---|
| 点「规划为卷」 | 这段范围里没有任何世界级事件 | 🟡 可能空心（允许，但请标为过渡卷） |
| 点「规划为卷」 | 这段范围横跨了某个世界事件的中间 | ⚪ 建议对齐事件边界 |
| 点「规划为集」 | 只选了 1 个事件 | 🟡 一条线不是集，是章 |
| 点「规划为集」 | 选中的事件彼此不交叉 | 🟡 各写各的 |
| 挂到章 | 这一章没有具体内容（动作/台词/细节） | 🔴 必然写成概述 |
| 任何时候 | 事件未落入任何卷（悬空） | 🟡 大纲有洞 |
| 任何时候 | 结已打完但排不进任何章 | 🟡 线头 |

**过渡卷是被允许的**，条件是：至少推进一条线，并留下一个结（或明确标记为“有意留白”）。

## 结构单位与事件尺度同构（用于推导，不用于约束）

| 结构单位 | 通常对应事件尺度 | 特征 |
|---|---|---|
| **卷** | 世界事件 | 起因 → 发展 → 高潮 → 结尾 |
| **集** | 地区事件（一个或多个） | **多线并行**，多实体、多视角 |
| **章** | 个人事件（一件或几件小事） | **具体**：发生了什么、说了什么、怎么打的 |
| 场景 | 事件的展开单位 | 四格（schema 归 L4） |

“同构”是切卷切集时的**默认建议**，不是硬规则——你可以框任意范围成卷。

## 多线叙事的结构依据

> **不是“作者想切视角”，是同一个世界事件在不同地区、不同人身上的投影必须分别讲。**

```
世界事件：天下第一武道会
   ├─ 地区投影 A：擂台（宗门、旧敌、裁判）      → 线 A
   ├─ 地区投影 B：主办方密室（刺杀密谋）        → 线 B
   ├─ 地区投影 C：城里暗市（押注与消息）        → 线 C
   └─ 个人投影：主角赢了，但漏了底牌           → 章的落点
```

## 卷：四阶段

| 阶段 | 必须做到 | 缺了会怎样 |
|---|---|---|
| 起因 | 交代这件事为什么**现在**发生 | 突兀 |
| 发展 | 各方入局、关系变复杂、筹码升高 | 直接跳高潮，读者不紧张 |
| 高潮 | 正面相撞 | 没有记忆点 |
| 结尾 | 代价结算、新格局成形、旧问题收束 | 卷与卷之间断裂 |

每阶段由若干集承载。四阶段齐备是 🟡 提醒，不是硬门禁。

## 集：多线 + 交叉（三个硬指标）

1. **至少两条线**（只有一条线，那是章）
2. **每条线必须推进**（零推进是凑数）
3. **线之间必须交叉**（从头到尾不相遇，就是一个集里塞了两篇短篇）

```yaml
集 15 · 外围赛
线 A｜主角     一路赢，被迫用出底牌        推进：胜场 3 / 暴露风险 +1
线 B｜旧敌     买通裁判                    推进：与 C 线接头
线 C｜主办方   决定决赛夜动手              推进：刺杀方案成形
线 D｜暗市     押主角输，赔率异常          推进：消息传到 B 线

交叉点    第 78 章（A×B 擂台相遇）· 第 82 章（C 动手，A×C 首次相撞）
集末状态  主角进决赛、旧敌出局、刺杀箭在弦上
```

**「交叉点」是多线叙事的关键**：线必须在事件上真的相撞，而不是在时间上并行。

## 章：必须具体

> 卷和集是“发生了什么”，章是“**那一刻是什么样子**”。

一章承载 1–3 件小事，必须落到：谁做了什么动作、说了什么话、环境里有什么、打起来怎么打的。

```yaml
章 78 · 擂台
所属集    15
线        A（主角） × B（旧敌）
事件      个人事件：一场胜负
具体内容  三回合交手（试探 / 受伤 / 险胜）
          关键对话：旧敌说出她父亲的名字
          关键细节：她左手袖口裂开，露出缝着的名字
本章改变  她赢了，但底牌漏了一半
本章新问题 旧敌怎么知道她父亲的名字
禁止      不出现主办方的人
```

**「具体内容」是硬要求**：填不出动作、台词、细节，这章不许开写——否则必然写成概述，这是长篇最常见的塌陷方式。

## 校验（X 系列）

| # | 触发 | 灯 |
|---|---|---|
| X1 | 卷缺四阶段之一 | 🟡 |
| X2 | 卷提出的问题未解决，也未转交下一卷 | 🔴 |
| X3 | 集内少于 2 条线（其实是章） | 🟡 |
| X4 | 集内某条线零推进（凑数） | 🟡 |
| X5 | 集内线之间从无交叉（各写各的） | 🟡 |
| X6 | 一章内视角切换超过 3 次（晕） | ⚪ |
| X7 | 章的「具体内容」填不出动作/台词/细节（会写成概述） | 🔴 |
| X8 | 章与所属集的目标无关（离题） | 🟡 |
| X9 | 章内事件与编年史不符（时间/地点/在场） | 🔴 |
| X10 | 某条线跨集但连续 N 集未出现（读者已忘） | 🟡 |
| X11 | 集的推进与卷的阶段不匹配（发展段里写高潮的事） | 🟡 |
| X12 | 本章无状态变化（“改变了什么”填不出来） | 🔴 |
| X13 | 章末无未解问题（读者没有回来的结构理由） | 🟡 |
| X14 | 本章未留下任何可复述的锚点（隔周即忘） | ⚪ |
| X15 | 信息密度失衡（新专名/新设定 > 5 或 = 0） | 🟡 |

**X5 与 X7 最关键**：一个防“多线写成散文集”，一个防“章写成大纲”。

## 连载形式带来的四条结构约束

（形式约束，不是题材配方——与“爽点/打脸债/升级阶梯”无关）

| 约束 | 结构上必须成立 |
|---|---|
| 章是离散交付单位 | 每章相对自足，单独读也成立 |
| 阅读有间隔 | 必须对抗遗忘：留下**复述锚点** |
| 章末是天然停顿点 | 必须留下**一个未解决的问题**（形态不限） |
| 一次只能吃一口 | 信息密度有上下限 |

## 三张视图

| 视图 | 管什么 |
|---|---|
| 卷表 | 四阶段 + 段落分配 + 每阶段由哪些集承载 |
| 集线表 | 集内各线并行进度 + 交叉点 + 集末状态 |
| 章卡 | 单章的全部输入，写前填、写后核 |

## 待决策

- 卷/集/章 是否允许跨卷的线（跨卷长线如何表达）
- 一章是否允许承载两条不相干的线（当前：允许，但计入 X6）

# L6 · 创作阶段（片场）

## 定位

创作阶段是一个**模拟片场**：各部门拿着不同的信息、按工序交接，导演是唯一的两道闸门。

> **产出不是成品，是可以拿来改的实录。** 定稿那一步仍然是作者的笔——但那时手上已经有一份带场记批注、带造型细节、被剪辑砍过一轮的实录。

## 组织与信息流

| 部门 | 拿什么 | 从哪拿 | 产出 |
|---|---|---|---|
| **导演** | 全部数据 + 全部产出 | 直接读 | 布置单、规定情境、审查意见、终审签字 |
| **演员**（每角色一个） | 只接导演写的**规定情境** | **没有任何查询接口** | 表演（台词 / 动作） |
| **场记** | 环境与连续性 | 自取 `placeAt` + `ledger` | 置景单（时辰、布局、道具、声响、天气、人群） |
| **灯光与妆造** | 人物外观 | 自取 `profile.外观` + `ledger`（伤 / 衣着） | 造型单（面容、伤、衣着、手持物、光源） |
| **剪辑** | 成品与结构标准 | 自取 实录 + 章卡 + 集 + 时间轴 | 剪辑意见（质检 / 裁减 / 断点） |

**唯一的结构性约束：演员没有接口。**

> 场记知道明天要下雨、灯知道她袖口是破的、剪辑知道这一章要让她漏底牌——**这些不是秘密，是剧组该知道的**。只有演员的认知是「角色内」的，他只能知道角色此刻知道的。

## 工序与两扇门

```
① 开机     导演：这一章要发生什么 → 分镜（章卡落地）
② 布置     导演：为每个部门定义"要什么、范围多大、什么不许碰"
③ 产出     各部门自取数、各自产出；演员按情境上场
④ 审查     导演：输入合规？输出达标？
              ├─ ✅ 通过 → 下一工序
              └─ ⚠ 退回（带理由 + 重做范围）
⑤ 后期     剪辑：质检 / 裁减 / 约束过度表演 / 报断点
⑥ 终审     导演：五部门全过 + 签字 → 这一章才算完成
```

状态机：

```
待布置 → 已布置 → 产出中 → 待审 → ✅ 通过
                            └→ ⚠ 退回（理由 + 重做范围）→ 产出中
```

**退回必须带范围**，因为范围决定成本：

| 重做范围 | 例 |
|---|---|
| 局部重演 | “只重演第 3 轮，前两轮保留” |
| 重写单子 | “造型单里她的伤写错了，重出” |
| 重新取数 | “场记没查季节，重新查一遍” |
| 整份作废 | 罕见，通常是布置就错了 |

## 导演审查：两个维度

| 维度 | 问什么 | 判据 |
|---|---|---|
| **输入合规** | 取的数据对不对？范围够不够？够没够到不该够的？ | 演员：**结构上没有接口**；其他人：范围是否覆盖本章所需、有没有越界读未来 |
| **输出达标** | 置景跟地理切片对得上吗？造型跟台账的伤对得上吗？剪辑抓的是真问题吗？ | **跑校验器** + 台账比对 + 章卡目标 |

> **审查不是凭感觉，是「规则报告 + 导演裁决」。** 机器给证据，人给判断。

## 规定情境：唯一的分发物

导演读全部，然后为每个演员写一段规定情境。**这是整条链上唯一由人写、不来自查询的分发物。**

```markdown
**阿缇 · 第 78 章 · 场景 2**

你是谁      抄名匠，二十四岁；说话短，常不说完
这一场      赢下来，且不让人看见袖口的字
你不能      承认翻过他的柜子
你怕        他会发现我在抄他的名字
你以为      旧敌比我高两阶
            记得三十年前所有人的名字（七成信）
你欠着      甲部一条命（未还）
此刻        擂台上，第三轮将开始，左肋还在疼
你说话      短句；不叫「大人」；紧张时重复对方的词
```

**导演给的是该角色的视角版本，不是真相。** 他信错的事就写错的版本——查 `perspective(event, holder)` 拿到的天然就是他以为的那版，不需要额外机制。

导演的责任只有一条，也是最要紧的一条：

> **这句话，是只有我知道、而他此刻不该知道的吗？**

命中就删。这一步留在导演的工作流里，系统不设闸门——设了闸门就等于说“系统替你负责”，而这件事的责任本来就在导演身上。

## 实录与三色标记

```
【第 78 章 · 场景 2 · 擂台】   在场：阿缇 / 旧敌
导演 · 开拍令：这一场在第 4 轮翻面，她赢了但漏底牌

旧敌   你父亲的名字，我记得。
                        ◇ 灯光妆造：台下有人剥橘子，酸味压过血腥味
阿缇   （没有停手）
旧敌   你连他叫什么都不知道吧。
       ⚠ 场记：这句成立，但上一场她刚说过「我爹早死了」，重复。
阿缇   ……你再说一遍。

导演 · 喊咔
剪辑   ✂ 断在这个问句上，不要给答案。全集第 3 个断点，间隔合适
```

三种标记，三种用途：**⚠ 是错（必须处理）· ◇ 是素材（可选）· ✂ 是结构建议（可选）**。

## 连续性台账（新对象）

场记手里那份东西，之前系统里没有，但它必须存在：

```yaml
台账（由已采纳的正文自动累积）
  时间    纪元 615 年 霜月 第 3 日 黄昏
  地点    断脉关 · 关下镇 · 擂台
  在场    阿缇 · 旧敌 · 观众约 200
  伤情    阿缇：左肋挫伤（第 76 章）· 左袖已裂（第 76 章）
  持有    她身上有半张脉正的名录（第 74 章）
  知情    知道：觉明记得三十年前的人（0.6）／不知道：觉明在吞记忆
  承诺    欠甲部一条命（未还）
```

**这是“改稿牵一发动全身”的另一半**：正文里写下的每个物理事实都进台账，之后任何一章再写，场记都能立刻比对。

## 校验（D 系列）

| # | 触发 | 灯 |
|---|---|---|
| D1 | 演员说了规定情境以外的事（越界） | 🔴 |
| D2 | 台词提到尚未发生 / 尚未揭示的事（剧透） | 🟡 |
| D3 | 一场戏里情绪峰值 >2 次（过度表演） | 🟡 |
| D4 | 台词换个同阶层的人说也成立（人设漂移） | ⚪ |
| D5 | 置景与地理切片矛盾（该地尚未入冬却写大雪） | 🟡 |
| D6 | 造型与台账矛盾（袖口第 76 章已裂，此处再裂） | 🔴 |
| D7 | 剪辑意见标了问题但未被处理 | 🟡 |
| D8 | 五部门未全过 / 终审未签字 | 🟡 章不算完成 |
| D9 | 过程档案缺失，或与 `07-final` 不一致 | ⚪ 无法润色 |

## 作者的位置

**制片人**：定这一章要什么、随时能喊停、最终挑哪几句进正文。五个部门是剧组，不是代笔。

## 分期

- **P2**：三对象结构（规定情境 / 实录 / 台账）、档案落盘、事实抽取（先能存能抽，不演）
- **P3**：单场景（导演 + 两演员 + 场记），含审查与退回
- **P4**：全部门、局部重演、剪辑裁减、终审签字
